# 바이렌워크 — 새 직원이 왔을 때 / 나갈 때

> 이 문서는 **두 부분**입니다.
> **1부**는 관리자(경영지원)가 하는 일, **2부**는 새 직원에게 그대로 보내도 되는 안내,
> **3부**는 퇴사할 때. 1부를 위에서부터 순서대로 하면 됩니다.
>
> 주소: **work.viren.kr** · 마지막 손질 2026-10-26

---

## 1부. 관리자가 하는 일 (순서대로)

### ① 계정 만들기 — Supabase 대시보드

바이렌워크 화면에는 "직원 추가" 단추가 **없습니다.** 계정은 Supabase 에서 만듭니다.

1. Supabase → 프로젝트 `viren-work` → 왼쪽 **Authentication** → **Users**
2. **Add user** → **Create new user**
3. 회사 메일(`이름@viren.kr`)과 **임시 비밀번호**를 넣고 만듭니다
4. 임시 비밀번호는 본인에게 따로 전달합니다 (메신저·문자 등)

> **왜 화면에 없나** — 회원가입을 열어 두면 외부인이 들어올 수 있습니다. 계정 만들기는
> Supabase 에서만 되게 막아 두었습니다.

만들면 직원 줄이 **자동으로 생기는데, '재직'이 꺼진 상태**입니다. 그대로는 로그인해도
아무것도 못 봅니다. ②에서 켜야 합니다. (이중 잠금입니다)

### ② 재직 켜고 기본 정보 넣기 — 관리 → 직원

바이렌워크 → **관리** → **직원** → 왼쪽 목록에서 그 사람을 고릅니다.

| 자리 | 넣을 것 |
|---|---|
| **기본 정보** | 이름 · 부서 · 직급 · 직책 · **입사일** |
| **연차** | 보통 비워 둡니다(입사일로 자동 계산). 따로 정한 게 있으면 '연차 직접 지정' |
| **권한 및 재직** | 권한은 `직원`. **`재직 중` 체크 ← 이걸 켜야 쓸 수 있습니다** |

- **이메일은 못 고칩니다.** 잘못 만들었으면 Supabase 에서 계정을 다시 만듭니다.
- **입사일을 꼭 넣으세요.** 연차가 입사일로 계산됩니다. 비워 두면 연차가 안 생깁니다.
- 목록에 나오는 **순서**는 줄을 끌어서 바꿉니다.

### ③ 인사기록 (필요할 때)

관리 → 직원 → **[인사기록]** 에서 학력·경력·자격증을 넣습니다.
**기술자등급·디자이너등급**은 여기서 기준표를 보고 정합니다. 직원 상세에는 **보이기만** 합니다
(고치는 자리가 둘이면 값이 갈라져서, 고치는 건 인사기록 한 곳으로 모았습니다).

경력은 **건강보험 자격득실확인서** 기준으로 넣습니다. 입사일과 다를 수 있어서 날짜를 고칠 수 있게 해 두었습니다.

### ④ 메신저 — 단체방에 넣기

- **대표메일 알림** 방은 **자동**입니다. 다음 메일이 올 때 재직자 전원이 들어갑니다. 할 일 없습니다.
- **전체 공지** 같은 단체방은 **직접 초대**해야 합니다. 그 방에 들어가서 `+ 초대`.

### ⑤ 본인에게 2부를 보내기

아래 **2부**를 그대로 복사해서 보내면 됩니다. 특히 **알림 켜기**는 본인이 자기 기기에서
해야 하고, 안 하면 결재가 와도 모릅니다.

### ⑥ 며칠 뒤 확인할 것

- 출근·퇴근이 찍히고 있는지 (근태 화면)
- 결재 알림을 받는지 (본인에게 물어보기)
- 연차 일수가 맞는지

## 2부. 새로 오신 분께 (그대로 보내셔도 됩니다)

### 바이렌워크 시작하기

바이렌워크는 **결재 · 근태 · 캘린더 · 메신저**를 한곳에서 쓰는 사내 시스템입니다.
주소는 **work.viren.kr** 입니다.

#### 1. 로그인하고 비밀번호 바꾸기

1. **work.viren.kr** 접속
2. 회사 메일 + 받으신 임시 비밀번호로 로그인
3. 오른쪽 위 **내 정보** → **비밀번호 변경** (8자 이상)

#### 2. 휴대폰에 앱으로 깔기

브라우저로도 쓸 수 있지만, **앱으로 깔아야 알림이 옵니다.**

- **아이폰** — 사파리로 열고 → 아래 공유 단추 → **홈 화면에 추가**
  > ⚠️ 아이폰은 **반드시** 이렇게 해야 합니다. 사파리로 그냥 열어 두면 알림이 오지 않습니다.
- **안드로이드** — 크롬으로 열면 "앱 설치" 안내가 뜹니다
- **PC** — 주소창 오른쪽 설치 아이콘

**내 정보 → 앱으로 쓰기** 에 기기별 방법이 적혀 있습니다.

#### 3. 알림 켜기 — 기기마다 따로

**내 정보 → 기기 알림** → 켜기.

> ⚠️ **기기마다 따로 켜야 합니다.** 휴대폰에서 켜도 PC 에서는 따로 켜야 합니다.
> 안 켜면 결재 차례가 와도, 메신저가 와도 모릅니다.

켜고 나서 **시험 알림**이 오는지 확인하세요.

#### 4. 내 메일 알림 (원하면)

**내 정보 → 내 메일 알림** 에서 켜면, 내 카카오워크 메일함에 새 메일이 올 때
메신저 **‘내 메일 알림’** 방으로 알려 줍니다. **그 방은 본인만 봅니다.**

- 보낸사람과 **제목만** 보입니다. 본문은 가져오지 않습니다
- 켜려면 카카오워크에서 **POP3/IMAP 연동 비밀번호**를 따로 만들어 넣어야 합니다
  (화면에 1·2·3 으로 적혀 있습니다). **로그인 비밀번호가 아닙니다**
- 안 켜도 됩니다. 카카오워크가 이미 알려주고 있으니까요
- 언제든 끄거나 지울 수 있고, 카카오워크에서 그 비밀번호만 끊어도 됩니다

> 비밀번호는 암호로 바꿔 보관하고 **푸는 열쇠는 다른 곳(Cloudflare)에** 둡니다.
> 그래도 "바이렌워크가 내 메일함에 들어갈 수 있다"는 사실은 남습니다. 그게 싫으면 안 켜셔도 됩니다.

#### 5. 매일 하는 것

- **근태** — 출근할 때 `출근`, 갈 때 `퇴근`. 하루 9시간 기준으로 막대가 찹니다
- **결재** — 내 차례가 오면 알림이 옵니다. 품의서·휴가신청서·지출결의서를 올릴 수 있습니다
- **캘린더** — 회사 일정과 공휴일
- **메신저** — 사내 대화. 대화 내용은 바이렌워크 안에만 남습니다

#### 6. 메신저 쓰는 법

- **스티커** — 글칸 왼쪽 웃는 얼굴 단추
- **사진** — `+` 로 고르거나, 캡처한 그림을 **Ctrl+V** 로 붙여넣고 `보내기`
- **읽음 표시** — 내가 보낸 글 옆에 `읽음` / `안읽음`
- **메일 알림** — 목록 위쪽 `메일 알림` 묶음. 회사 대표메일(`viren@viren.kr`)로 메일이 오면
  여기에 뜹니다. **읽고 답하는 건 카카오워크에서** 합니다

#### 7. 막히면

- 정보가 틀렸으면(이름·부서·직급·입사일) **관리자에게 요청**하세요. 본인은 못 고칩니다
- 비밀번호를 잊으면 관리자에게 말씀하세요

## 3부. 퇴사할 때

### ① 재직 끄기 — 관리 → 직원 → `재직 중` 체크 해제

**계정을 지우지 마세요.** 지난 결재 문서·근태 기록·메신저 글이 그 사람을 가리키고 있어서,
지우면 기록이 깨집니다. **재직만 끄면** 됩니다.

재직을 끄면 바로:
- 로그인해도 아무것도 못 봅니다
- 직원 목록·결재자 고르기에서 사라집니다
- 휴대폰 알림도 **안 갑니다** (2026-10-26에 막았습니다)

### ② 남아 있는 것 (그대로 둬도 됩니다)

- 지난 결재·근태·메신저 기록 — 남습니다. 남아야 합니다
- 등록해 둔 기기 — 남지만 **알림은 안 갑니다**
- 대화방 참여 — 남지만 **못 들어갑니다**

### ③ 회사 메일

바이렌워크와 별개입니다. **카카오워크**에서 따로 정리하세요.

## 자주 막히는 곳

| 증상 | 까닭 |
|---|---|
| 로그인은 되는데 화면이 비어 있다 | **재직이 꺼져 있음** → 관리 → 직원에서 켜기 |
| 연차가 0일로 나온다 | **입사일이 비어 있음** |
| 알림이 안 온다 | 기기 알림을 안 켬 / 아이폰인데 홈 화면에 추가를 안 함 |
| 결재자 목록에 안 보인다 | 재직이 꺼져 있음 |
| 기술자등급이 '—' 로 나온다 | 인사기록에 학력·경력이 없음 |
