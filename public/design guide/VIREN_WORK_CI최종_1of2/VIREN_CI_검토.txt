VIREN CI 검토 — 18쪽 PDF와 승인 홈/근태 A 시안 비교
페이지 번호는 표지 포함 PDF 순서입니다. PDF는 텍스트 추출이 되지 않아 페이지 렌더링으로 확인했습니다.

바로 반영할 방향
승인된 연보라 배경 + 화이트 카드 + 노란 포인트 + 평면 아이콘의 분위기는 유지하되, 로고와 핵심 브랜드색부터 맞추는 최소 수정이 적절합니다. 연보라를 공식 브랜드색이라고 부르거나 CI 준수 완료라고 단정하지 않습니다.

명시된 기준
• p.5: 심벌 최소 높이 Screen 15px / Print 5mm. 이 수치를 전체 로고의 최소 폭으로 해석하면 안 됩니다.
• p.6: 세로 시그니처는 로고 높이 A=10a 기준 사방 3a의 보호공간. 가로 시그니처는 로고 높이 A=10a 기준 사방 5a. 원본 데이터로 비례 확대·축소하고 조합·간격을 변경하지 않습니다.
• p.7: 일체형 워드마크는 높이 A=10a 기준 사방 5a 보호공간. 원본 형태와 비율을 유지합니다.
• p.8: 임의 색상, 형태 왜곡, 복잡한 이미지 위 배치, 색상/명도/채도가 유사한 바탕, 로고 그림자·테두리 효과, 임의 윤곽선 처리를 금지합니다. 이는 로고 사용규정이며 UI 카드 전체의 그림자 금지로 확대 해석하지 않습니다.
• pp.9–10: 백색 배경에서 정색 사용이 가장 바람직하며 다른 배경에는 정해진 조합을 적용합니다. 시그니처: 흰 배경에 노란 심벌+검정 글자; 노란 배경에 검정; 네이비/검정 배경에 노란 심벌+흰 글자. 일체형 워드마크: 흰 배경에 노랑; 노란 배경에 어두운 색; 네이비/검정 배경에 노랑. 흑백 조합도 제시됩니다.
• p.11: 전용색은 지정값을 정확히 사용하도록 명시합니다.
  Vivid Yellow: Pantone 123 C; CMYK 0/25/87/0; RGB 251/200/37; HEX #fbc825.
  Solid Navy: Pantone 5395 C; CMYK 100/77/53/68; RGB 0/24/44; HEX #00182c.
  Black: Pantone Black C; CMYK 0/0/0/100; RGB 0/0/0; HEX #000000.
  Gray 1: Pantone Coolgray 2c; CMYK 0/0/0/20; RGB 207/207/207; HEX #D0D0CC.
  Gray 2: Pantone Coolgray 7c; CMYK 0/0/0/50; RGB 160/160/160; HEX #989999.
  Gray 3: Pantone Coolgray 9c; CMYK 0/0/0/70; RGB 113/113/113; HEX #76777A.
  White는 색명만 있고 RGB/HEX 수치가 표시되지 않습니다.
  주의: Gray 1–3는 PDF의 RGB와 HEX가 서로 일치하지 않습니다. 위 값은 원문 그대로이며 임의 보정/변환값이 아닙니다. 실제 구현 시 어떤 값을 우선할지 CI 담당 확인이 필요합니다. Yellow/Navy/Black은 RGB와 HEX가 일치합니다.
• p.13: 명함 A/B의 정보 영역에 Font: Noto Sans가 명시됩니다. 문서 전체 또는 웹 UI 필수 서체라고 명시되지는 않았습니다. 로고는 일반 글꼴로 재작성하지 않습니다.
• p.5 브랜드 의미: V-DYNAMIC(정체성·성취/승리), ASCENDING WING(혁신적 도약·성장·미래지향·진취성), SYNERGY LOOP(고객과의 연결·시너지·확장 가능성).
• p.4: 임의 변경을 금지하며 해석이 불명확한 적용은 CI 담당자 검수를 요구합니다.

현재 홈/근태 A 시안과의 차이 및 최소 수정 제안
1. 두 시안 좌상단 VIREN WORK는 일반 대문자 텍스트입니다. 공식 로고로 쓰려는 자리라면 p.6 또는 p.7 원본 로고로 VIREN 부분을 교체하고 WORK는 보호공간 밖의 제품명으로 분리합니다. 로고 자리를 깨끗한 흰 배경으로 두면 가이드에 가장 충실합니다.
2. 현재 노란 버튼/선택선/주황빛 진행 막대와 짙은 보라빛 텍스트는 CI 색으로 정확히 통일되어 있지 않습니다. 브랜드 포인트 토큰은 #FBC825, 주요 제목·네비게이션의 브랜드 네이비 토큰은 #00182C로 정리하는 것이 권장됩니다. 이는 래스터 시안의 시각 비교이며 구현 CSS 값을 검사한 결과는 아닙니다. 연한 배경 tint는 원색이 아닌 UI 파생색으로 구분합니다.
3. 연보라 배경은 CI 팔레트에 없는 색입니다. 그러나 가이드가 UI 보조 배경 전체를 별도로 규정하지는 않습니다. 승인된 느낌을 보존하는 UI 확장색으로 낮은 강도로 유지하고, 로고 주변에서는 제거하는 방안이 최소 변경입니다. 엄격한 CI 적용이 필요하면 담당자 확인이 필요합니다.
4. 상태용 초록/파랑/주황 및 YouTube 등 외부 서비스색은 브랜드색이 아니라 기능/서비스 식별색으로 구분해 유지할 수 있다는 디자인 제안입니다. 가이드에 이러한 UI 색 사용의 명시적 허가가 있는 것은 아닙니다.
5. 한국어 본문은 Noto Sans 계열로 맞추면 명함의 서체와 연속성이 생깁니다. 현재 PNG에서 정확한 사용 폰트는 확인할 수 없어 폰트 위반이라고 단정할 수 없습니다.
6. 평면적인 구성과 선형 아이콘은 유지합니다. 로고에는 그림자·글로우·외곽선·3D 효과를 적용하지 않습니다. 현재 시안의 일반 UI 카드/배경 효과까지 제거할 필요는 없습니다.

별도 품질 메모(CI 규정 아님)
근태 A는 요약 배지 '근무 중'이 초록인데 범례의 '근무 중'은 노랑, 선택일 표시도 주황 계열이라 상태 대응이 일관되지 않습니다. 사용자 승인 구조는 유지하면서 배지/범례/달력의 상태색 의미를 통일하면 좋습니다.
